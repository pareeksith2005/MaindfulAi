# Internship Application Analyzer

## Problem Statement
Automate the processing and shortlisting of internship applications by validating, removing duplicates, and ranking candidates.

## Features
- CSV-based input handling
- Duplicate removal (email-based)
- Application validation
- Skill-based scoring system
- Ranked shortlist output

## Scoring Logic
- Required Skill Match → +50
- Extra Skills → +10 each
- Full-Time → +20
- Experience ≥ 6 months → +20

## How to Run
python main.py
